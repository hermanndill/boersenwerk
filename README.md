## ⚡ Quick Start mit Replit

[![Run on Repl.it](https://replit.com/badge/github/IHRUSERNAME/boersenwerk)](https://replit.com/new/github/IHRUSERNAME/boersenwerk)

**Ersetzen Sie `IHRUSERNAME` mit Ihrem GitHub-Benutzernamen!**

## 🚀 Setup

### 1. Import nach Replit

1. Gehen Sie zu [Replit](https://replit.com)
2. Klicken Sie auf "Create Repl"
3. Wählen Sie "Import from GitHub"
4. URL: `https://github.com/IHRUSERNAME/boersenwerk`
5. Klicken Sie auf "Import from GitHub"

### 2. API-Key einrichten

1. Klicken Sie auf das 🔒 **Secrets** Symbol (links)
2. Fügen Sie hinzu:
   - Key: `ANTHROPIC_API_KEY`
   - Value: Ihr Claude API Key von https://console.anthropic.com

### 3. Server starten

1. Klicken Sie auf **"Run"** ▶️
2. Warten Sie auf: `🚀 Börsenwerk Backend startet...`
3. Öffnen Sie die URL, die Replit anzeigt

## 📊 Analyse-Kategorien

1. **Profitabilität (25%)** - Nettomarge, Bruttomarge, ROE, ROIC
2. **Wachstum (25%)** - Umsatz YoY, EPS, FCF
3. **Stabilität (20%)** - Debt-to-Equity, Interest Coverage, Current Ratio
4. **Bewertung (20%)** - KGV, KUV, KBV, PEG, EV/EBITDA
5. **Cashflow (10%)** - FCF, Payout Ratio, Dividendenrendite
